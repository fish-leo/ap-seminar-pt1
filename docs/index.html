    STEP 8

    口头答辩

    问题只有三类：你怎么知道 / 如果反过来呢 / 为什么没考虑 X。

    答题三句式

    ① 直接回答一句，不带「我觉得」 → ② 证据锚点（作者+年份+样本+结论方向） → ③ 边界承认（这份证据不能说明什么）。

    不会的题：「这一块我证据不足，我能说的是 __；要回答到那一步，我需要 __ 类型的数据。」

    工具与链接

    三个工具对应三道工序：查谬误 → 查格式 → 生成条目。

    1 · Logical Fallacy Is

    yourlogicalfallacyis.com

    用途：给对方的推理漏洞命名，写进可信度三句与反证段。

    什么时候：读到结论「太顺」时；确认自己的因果句没踩 false cause。

    评分落点：Row 2 / Row 3。

    2 · Purdue OWL (APA)

    owl.purdue.edu/owl/research_and_citation/apa_style

    用途：in-text 与 References 的权威规则，按来源类型查模板。

    什么时候：Draft 2 之前读一遍，一次统一全篇格式。

    Row 5 判据是「准确 + 一致」，先统一再逐条修。

    3 · Scribbr 引用生成

    scribbr.com/citation/generator

    用途：输入 DOI / URL / ISBN 生成条目，省手工。

    必须人工核对：作者顺序与大小写、年份、卷期页码。中文期刊与政府文件常出错。

    生成器给初稿，格式仍需按 OWL 校对。

    使用顺序

    读文献时用 Logical Fallacy 命名漏洞 → 登记时用 Scribbr 生成并核对 → Draft 2 前用 OWL 统一格式。

    注意：格式正确 ≠ 证据可信。Row 3 要的是自己写出的 credibility + relevance 判断。

    输入名字进入

    同名即同一人（忽略大小写与空格），不会重复建号。
